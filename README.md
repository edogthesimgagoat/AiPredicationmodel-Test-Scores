# AiPredicationmodel-Test-Scores
This is a folder of all my code. Its an Ai model that can prediet student scores based on factors using THONNY.
A Python machine learning project that predicts student test scores based on study time and sleep using linear regression.

Problem

I wanted to find out whether a computer can predict a student’s test score using two factors: hours studied and hours slept. This problem matters because prediction models like this are widely used in real-world applications such as education analytics, performance forecasting, and decision-making systems.

Solution

This project trains a machine learning model using historical data that includes study time, sleep time, and test scores. The model learns patterns in the data using linear regression and then predicts a test score for a new student based on their input values. The process demonstrates how AI systems learn from data and make predictions.

Tools

Python

pandas (data processing)

scikit-learn (machine learning)

Linear Regression

Google Sheets (dataset creation)

GitHub (project hosting)

Results – Output Screenshot

The trained model successfully predicts a realistic test score for a student who studied 6 hours and slept 8 hours. This shows that the model learned meaningful relationships between the input variables and the test score.

Learning

This project helped me understand how machine learning models are trained using real data and how Python libraries can be combined to build, test, and run an AI system from scratch.
